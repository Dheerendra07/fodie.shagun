# FoodieHub

A responsive food discovery and delivery frontend with dark and light themes.

## Deploy with GitHub Pages
1. Keep `index.html`, the SVG logo files, and `.nojekyll` in the repository root.
2. Open **Settings → Pages**.
3. Select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
4. Visit https://shagunchauhan299-sudo.github.io/fodie/

## Notes
This repository hosts the static frontend. Browser-local demo state is not a shared production backend.
The Node.js + SQLite backend must run on a separate server; GitHub Pages does not execute Node.js server code.
